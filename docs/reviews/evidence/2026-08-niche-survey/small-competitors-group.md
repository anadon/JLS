# Small direct competitors group: DEEDS (digitalelectronicsdeeds.com), Logic.ly, Gate Lab (lgsim.io), DigiSim (digisim.io), simulator.io, LogicCircuit (logiccircuit.org)

## FACTS
DEEDS: Closed-source freeware from DITEN, Univ. of Genoa (author Giuliano Donzellini). 32-bit Windows application requiring Win10+; runs on 64-bit Windows, but macOS/Linux users are officially told to use CrossOver or VirtualBox (https://www.digitalelectronicsdeeds.com/downloads.html, softwareinformer mirror). Version line ~2.50.x. Delphi-era native UI. Components: schematic editor, interactive "Animation" sim, separate timing simulator with timing diagrams, FSM editor, d-McE 8-bit microcomputer with assembler, VHDL converter, FPGA export/test module (https://www.digitalelectronicsdeeds.com/deeds.html). Tightly coupled to Springer textbook "Introduction to Digital Systems Design" (Donzellini et al., 2018, https://link.springer.com/book/10.1007/978-3-319-92804-3) — all book exercises run in Deeds; decades of course adoption, mostly EU. No public issue tracker, no source, single academic maintainer. LoC unknown (closed). | Logic.ly: Commercial desktop app (Windows+macOS) by solo dev Josh Tynjala, one-time license from ~$29/seat, school volume packs, licenses restricted to school-owned machines; sales via email (https://logic.ly/purchase/, https://logic.ly/purchase/faq/). Free zero-install web demo (https://logic.ly/demo/) as funnel; lessons pages (https://logic.ly/lessons/) and testimonials from K-12/GCSE/technical-college teachers (https://logic.ly/testimonials/). Started as Flash/AIR app in 2010 (https://joshblog.net/2010/12/10/...); blog activity is largely historical — mature/maintenance-mode product. Custom reusable "integrated circuits" supported (https://logic.ly/help/custom-circuits/). No delay-model documentation, no HDL export, no grading/CLI. Closed source. | Gate Lab (lgsim.io): free browser sim, 2024-2026 entrant; claims real-time simulation, live multiplayer collaboration, scriptable components, oscilloscopes, learn pages (https://lgsim.io/, https://lgsim.io/learn.html). No sign-up required. Zero discoverable HN/reddit/community traction. | DigiSim (digisim.io): freemium hosted sim, 2024-2026 entrant; 70+ components incl. CPU primitives, 70+ templates, "SimCast" narrated auto-building step-by-step lessons in 7 languages; Free tier = 32 cloud circuits + 4 lessons; Pro $32 one-time; Classroom $4/seat/year at 20+ seats; assignment workflow: distribute .digi starter files, student submission/review, embedded live circuits (https://digisim.io/, https://digisim.io/faq, https://digisim.io/changelog). Heavy SEO content marketing (self-published "vs Logisim-Evolution", "vs CircuitVerse", "Best simulators 2026" posts). No visible community traction. | simulator.io: free hosted web CAD for logic circuits with account-based saving (https://simulator.io/, /features, /samples); feature set static for years, shows browser-update warnings; classic frozen hosted tool, no education workflow, operator opaque. | LogicCircuit: free, open source (GitHub eugenelepekhin/LogicCircuit), C#/.NET WPF, Windows-only. 89 stars, 19 forks, ~1,497 commits, 6 open issues, 0 open PRs; build requires Visual Studio + WiX; no visible CI or CONTRIBUTING (https://github.com/eugenelepekhin/LogicCircuit). Active solo cadence: releases Feb/May/Jun/Dec 2024, Jan 2025, latest 2.25.06.10 (Jun 2025) (https://www.logiccircuit.org/ via search, https://www.softpedia.com/get/Science-CAD/LogicCircuit.shtml). Features: unrestricted circuit hierarchy, multi-bit buses, oscilloscope, run-mode hierarchy navigation, HDL export (added 2024), Python scripting (added 2024). Old SourceForge listing abandoned since 2019. Note: digitalelectronicsdeeds.com, logiccircuit.org, logic.ly, lgsim.io, simulator.io blocked direct fetch from this environment (proxy 403); facts above come from search-indexed snippets of those pages plus third-party mirrors.

- community_size: 3 — Real installed user bases exist — DEEDS has decades of university course adoption via its textbook, Logic.ly has paying K-12/GCSE schools, LogicCircuit 89 stars — but active developer community across all six is effectively one person each, and the 2024-26 web entrants show zero traction.
- momentum: 2 — DEEDS is on a single-academic sunset trajectory, Logic.ly is maintenance-mode, simulator.io is frozen, Gate Lab/DigiSim are launching-but-tractionless; only LogicCircuit shows steady releases (5 in 2024-25), all solo.

## TOP USER COMPLAINTS
- Platform lock: DEEDS is a 32-bit Windows-only app — macOS (which dropped 32-bit entirely) and Linux students are officially routed to CrossOver/VirtualBox (digitalelectronicsdeeds.com/downloads.html); LogicCircuit is Windows/.NET-WPF-only. This is the single loudest structural pain in the group and it worsens every year 32-bit x86 support erodes.
- Dated, cumbersome UI: DEEDS's Delphi-era chrome reads as retro even to sympathetic reviewers (jborza.com hardware-adventures review praises the sim, notes the vintage UI); LogicCircuit's only SourceForge review calls the interface 'slow, cumbersome, and confusing' with missing wire-manipulation basics (sourceforge.net/projects/logiccircuit/reviews).
- Hosted-tool data hostage risk: simulator.io saves circuits only behind its account system and has been visibly frozen for years with browser-compat warnings; DigiSim caps free users at 32 cloud circuits — when a solo-operated hosted sim dies, student work dies with it.
- Classroom paywall friction: Logic.ly licenses are per-seat, school-owned-machines-only, sales-by-email (logic.ly/purchase/faq); DigiSim locks most lessons and components behind Pro/$4-per-seat-per-year — teachers repeatedly route around this by using the save-less free web demo.
- No path to real hardware for most of the group: Logic.ly, Gate Lab, DigiSim, simulator.io have no HDL export at all; DEEDS's FPGA path is tied to specific boards and its VHDL converter to its own toolchain.
- Single-maintainer opacity: DEEDS has no public issue tracker (email-only feedback) and closed source; Logic.ly bugfixes depend on one developer; users report waiting on fixes with no visibility — no member offers public issue hygiene.
- Simulation naivety on feedback circuits: outside DEEDS's timing simulator, every member propagates events with undocumented semantics — no per-bit X/Z, no oscillation detection, no documented stability contract — so latches/ring circuits behave unpredictably and teachers can't explain why.
- No autograding/batch anything: instructors using these tools grade by eyeballing screenshots or opening each student file; DigiSim's submit-for-review workflow is the group's only acknowledgment of the problem and it is manual.

## DEV COMMUNITY
There is no developer community to harvest anywhere in this group — that is its defining shape. DEEDS: one academic author (Donzellini, Univ. Genoa) on a closed Delphi codebase with no tracker; contributors structurally impossible; the risk is retirement-driven abandonment of a 32-bit binary. Logic.ly: one commercial solo dev (Josh Tynjala) on a closed ex-Flash/AIR codebase; blog activity mostly historical; no contribution surface. Gate Lab / DigiSim / simulator.io: closed hosted SaaS run by anonymous or solo operators; DigiSim's public face is SEO comparison blogging, not engineering; simulator.io appears operator-abandoned. LogicCircuit is the only open repo and is still structurally solo: 1,497 commits essentially from one person, 0 open PRs, no CONTRIBUTING, no CI, and a Visual Studio + WiX Toolset build that filters out non-Windows contributors. What repels contributors across the board: closed source (4 of 6), Windows-locked toolchains (2 of 6), single-owner governance (6 of 6), and zero contributor documentation (6 of 6). Implication for JLS: there are no rival contributors to convert; the competition for developers is against these tools' non-existence of contributor infrastructure, which JLS already beats on paper (GPL, reproducible builds, CI, quality gates) — but JLS's 3 stars, 5,852-line god class, and single AI-assisted maintainer mean it has not yet converted that infrastructure into even one external contributor either.

## SWITCH ANALYSIS
### pull_users
(1) DEEDS instructors are the prize and the clock is on JLS's side: a closed 32-bit Windows binary maintained by one academic will hit a wall (32-bit deprecation, maintainer retirement, macOS-heavy student cohorts) with no source escape hatch. Pull = cross-platform signed installers + Nix/container + a delay-accurate timing simulator (the one DEEDS feature its users actually rely on) + batch grading DEEDS never had. Migration cost is real: no .pbs importer exists or is feasible (closed format), so instructors must rebuild lab handouts — JLS should ship a ready-made exercise pack mapped chapter-by-chapter to the Donzellini Springer textbook so the course transfers even though the files don't. (2) Hosted-entrant users (Gate Lab/DigiSim/simulator.io): pull = permanence — 'your files are local, GPL, and this tool will still run in 20 years'; simulator.io's freeze is the live demonstration. Adopt DigiSim's two genuinely good ideas: starter-file assignment distribution + submit/review workflow (trivial atop JLS batch grading), and SimCast-style guided build-along lessons. (3) LogicCircuit's loyal niche stays for multi-bit buses + oscilloscope + hierarchy navigation + speed; JLS cannot take them today. (4) Logic.ly's K-12 base is bought on polish and a web demo; not winnable without a web lane.
### pull_devs
Nothing to pull — none of the six has contributors to poach. The realistic dev play: (a) LogicCircuit's forkers (19 forks) are the only people in this group who ever tried to hack on a logic sim and were stopped by a Windows-only WPF/WiX toolchain — JLS's cross-platform Gradle/Nix build with CI is a strictly better home; (b) DEEDS-course TAs who want to automate grading have no code to touch at all — JLS's documented grading contract and test culture is the offer. Both pulls require JLS to fix its own contributor optics first: screenshots, a real CONTRIBUTING funnel, and breaking up the SimpleEditor god class so the codebase's elegance claim survives first contact.
### jls_deficits
Brutal list: (1) No zero-install path — every web entrant and Logic.ly's demo beats JLS's installer on first-touch friction, and for K-12/GCSE that is disqualifying. (2) No screenshots in README and no marketing surface at all vs Logic.ly's lessons/testimonials/demo funnel — JLS currently loses the evaluation before it starts. (3) No chronogram/timing-diagram panel — DEEDS's timing diagrams and LogicCircuit's oscilloscope are the exact features their users value; JLS's superior sim semantics are invisible without one. (4) No guided in-tool lessons vs SimCast's narrated auto-building tutorials; HTML 3.2 help in a Swing viewer is a generation behind. (5) No importers for .pbs/.CircuitProject/.logicly — every migration starts from zero. (6) No FSM design tool vs DEEDS. (7) No multi-bit bus ergonomics parity vs LogicCircuit; no subcircuit parameterization anywhere. (8) Swing-era UI perception vs Logic.ly's paid polish — FlatLaf helps but doesn't erase it. (9) 3 stars and one maintainer: JLS asks instructors to bet a course on a bus factor of 1, the same flaw it attacks in DEEDS.
### winnable_verdict
Winnable: (A) DEEDS-dependent instructors at forced-migration moments (platform sunset, lab refresh, maintainer retirement) — highest value, moderate cost; minimum bar: chronogram panel + FSM-adjacent tutorial content + a textbook-mapped lab pack + screenshot-rich landing page proving parity with the timing simulator. (B) Hosted-tool users/teachers burned by freezes and paywalls — low cost; minimum bar: DigiSim-style assignment starter/submit workflow on top of existing batch grading, plus permanence messaging. Conditionally winnable: (C) LogicCircuit's niche, only after bus ergonomics + oscilloscope/chronogram parity. Not winnable now: (D) Logic.ly's K-12 base — requires a zero-install web build (CheerpJ/WASM lane) and consumer-grade polish; treat Logic.ly as the on-ramp benchmark to copy, not a base to raid. Absolute minimum bar across all segments: screenshots + chronogram + one-click assignment workflow; without those three, JLS's genuine technical superiority (documented sim semantics, grading, HDL export, reproducible builds) never gets seen.
