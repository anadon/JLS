An issue whose acceptance criteria (AC-5), cost bands, and dependency graph rest entirely on content outside durable, citable history is unauditable by any reviewer, contributor, or the maintainer's future self without that specific branch.

**3. [High, scope] Eleven-feature, multi-year program compressed into a single issue for a bus-factor-1 educational tool.** By the issue's own arithmetic the required set is 83–137 mw (≈7–11 maintainer-years), plus five more gating issues (#315, #319, #322, #337, #348) that must land first, for a design target of 10^9–10^10 gates — orders of magnitude past anything the README/ARCHITECTURE describe JLS as being for ("Students draw circuits from gates, wires, registers... simulate them"). #508 independently quantifies the *entire* roadmap (of which this is one item) at ~600–1,700 mw against "bus factor 1 and a velocity baseline of one 4-week sprint, already tapering" — corroborating that this capstone's scale is not merely large but symptomatic of the project's broader over-commitment.

**4. [High, internal contradiction — self-corrected but pattern is systemic] Cost arithmetic has been wrong three times in this issue's own history.** The required sum moved 62–98 mw → 81–134 mw (with FEAT-057 silently mispriced at 4–5 mw against its own 6–8 mw feature-document band) → 83–137 mw, each "supersession" caught only by a later hand-audit comment. #508's own process findings admit this is systemic to the document-generation process used to produce these issues: "Spot-audit machine-generated arithmetic before filing (3 of 4 sampled capstones had bands below their own row sums)." Every number this issue asserts (150 B/element, 96.6 GB, 1,440 partition files, the 4.2x reachable-size claim) should be treated as unaudited until independently re-derived, not as settled fact merely because a later comment says "DECIDED."

**5. [Medium, gameable acceptance criteria] The one test that would falsify the whole capacity axis is deferred to the very end, after all eleven features report done.** §3 risk 7 concedes: *"FEAT-056 can pass its own criteria entirely over `LoopbackTransport` in one process; FEAT-055 can pass its own by writing and re-reading partition files without ever simulating them. That means 83–137 mw of work can land, each piece "green" by its own criteria, before the single end-to-end check that would expose a broken distributed-determinism story ever runs once — a textbook way for local acceptance criteria to pass while the stated capability silently fails to exist.
