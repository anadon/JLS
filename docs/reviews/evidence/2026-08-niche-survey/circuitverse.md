# CircuitVerse

## FACTS
STACK: Ruby on Rails monolith (auth, projects, groups/assignments, LTI) + browser simulator in legacy vanilla-JS/jQuery on HTML canvas; mid-flight rewrite to Vue 3 + TypeScript + Vite in separate repo cv-frontend-vue with parallel "v0 = stable production" and "v1 = experimental" trees (442 commits, 61 stars, 75 open PRs) [https://github.com/CircuitVerse/cv-frontend-vue]. Verilog import path is a Node service wrapping yosys2digitaljs [https://github.com/CircuitVerse/yosys2digitaljs-server]. Desktop app = Tauri wrapper (GSoC 2025, manual workflow_dispatch release pipeline, WebView2/Web Serial) [https://blog.circuitverse.org/posts/harsh_rao_2025_final_report/]. Mobile = Flutter app, 92 stars [https://github.com/CircuitVerse/mobile-app]. LICENSE: MIT. SIZE/COMMUNITY NUMBERS: main repo 1,243 stars, 2.1k forks, 612 open issues [https://github.com/CircuitVerse/CircuitVerse]; org 20 repos, 715 followers; claims 1.1M+ hosted circuits (excluding university self-hosts). LoC not published; simulator is a few tens of kLoC of ES5-era JS. RELEASES: continuously deployed web app, no semver web releases; Tauri desktop releases started 2025. INSTALL PATHS: circuitverse.org (zero install), embeds/iframes, self-host via Docker/SETUP.md/GitHub Codespaces video walkthrough, Tauri desktop beta, Flutter app stores. DOCS: docs.circuitverse.org user manual + Interactive Book on digital logic (167 stars) [https://github.com/CircuitVerse/Interactive-Book]; educator flow documented (groups, deadlines, grading scales, element restriction) [https://circuitverse-docs.netlify.app/chapter2/chapter2-cvforeducators/]; grading is MANUAL, teacher assigns grades only after the deadline passes — no test-vector autograding, though the simulator has an interactive TestBench panel and a timing-diagram (chronogram) panel with per-element Delay attribute. SIM SEMANTICS: event-queue simulation with contention detection and a stability/cycle limit; "delay" acts as queue priority, not true simulated time, and clock/flag/step timing is unsynchronized (issue #1412) [https://github.com/CircuitVerse/CircuitVerse/issues/1412]; GSoC'23 "Simulator Stability" project replaced the event queue with a binary heap and added crash-recovery autosave to localStorage because crashes lost user work [https://blog.circuitverse.org/posts/prerna-gsoc23-final-report/]. LMS: LTI integration for Moodle/Canvas incl. grade passback shipped GSoC 2021 [https://blog.circuitverse.org/posts/ayan-biswas-gsoc-21-final-report-lms-integration/]; Google Classroom not supported (#2661). GSoC org every year since 2019 through announced 2026 projects.

## SCORES
- onramp_install: 5 — Zero-install web app at a URL, shareable/embeddable circuits, plus Codespaces one-click dev env — category-best friction (nothing to install, not even an account to try it).
- onramp_learning: 4 — Interactive Book, docs site, 1.1M browsable example circuits and featured gallery get a student to first circuit in minutes, but no in-tool guided tutorial and docs have gaps (issue #377 asks for a step-by-step simulator guide).
- tech_sim_semantics: 2 — Delay is queue-priority rather than simulated time and clock/flag/step are unsynchronized (#1412); contention detection exists but throws wrong/cryptic errors (#5328, #2198); no per-bit X, no documented semantics contract — though it does have a timing-diagram panel JLS lacks.
- tech_scale_perf: 2 — No published throughput numbers; documented history of crashes and slowdowns on large circuits severe enough to warrant a dedicated GSoC'23 stability project (binary-heap event queue, crash-recovery autosave).
- tech_hierarchy_reuse: 3 — Subcircuits with custom layout editing exist and are widely used, but carry long-standing bugs (nodes disconnect on layout resize #349, dialog overflow #899, no reordering #84) and there is no parameterization or cross-project library mechanism beyond copy/embed.
- tech_testing_grading: 2 — In-browser TestBench panel exists, but grading is manual (teacher assigns a grade from a scale after the deadline), no CLI/batch vectors, no determinism contract, no autograde ecosystem — the LTI integration passes back manually-entered grades.
- tech_hdl_interop: 2 — Both Verilog import (yosys2digitaljs) and export exist on paper, but export can alter logic and embedded Verilog subcircuits produce wrong assignments and contention errors (#5328, #1753); their yosys fork drifted 39 PRs behind upstream; a 2025 GSoC project is still firefighting it.
- extensibility: 2 — No plugin/scripting API — adding a component means a PR into the legacy jQuery-era simulator core (or the half-migrated Vue tree), and the alternative extension path (Verilog module embed) is the buggy one.
- code_elegance: 2 — Rails monolith plus an ES5 jQuery canvas simulator that has been mid-rewrite to Vue for ~4 years with v0/v1 parallel trees, 612 open issues and a 75-PR backlog on the rewrite repo; simulator-core test culture is thin compared to the Rails side.
- contributor_experience: 3 — Excellent onboarding surface (Codespaces video setup, active Slack, GSoC mentorship pipeline, labeled beginner issues since issue #2) but chronic review bottleneck — large open-PR backlogs and years-old open issues signal merge latency.
- community_size: 5 — 1.1M+ hosted circuits, 1.2k stars/2.1k forks, 715 org followers, hundreds of lifetime contributors and a yearly GSoC intake — the largest user base of any open-source educational logic simulator.
- momentum: 4 — Continuously deployed, GSoC org every year 2019–2026 with active Vue/Tauri/Flutter/Verilog workstreams; docked a point because the core simulator rewrite has dragged 4+ years without cutover and star growth is flat.

## TOP USER COMPLAINTS
- Simulator crashes that lose hours of student work — recurring since issue #34 ('Crashing and Autosave'); severe enough that GSoC'23 shipped localStorage crash-recovery ('We have detected an unexpected simulator crash... recover your project'), and offline saves still vanish if browser data is cleared (https://github.com/CircuitVerse/CircuitVerse/issues/34)
- Slow/unstable simulation of large circuits — the GSoC'23 Simulator Stability project explicitly targeted 'crashes, slow performance, and unexpected behavior' on complex circuits; browser CPU/memory pressure is the standard cited limitation vs desktop tools (https://blog.circuitverse.org/posts/prerna-gsoc23-final-report/)
- Verilog is unreliable in both directions — export produces altered logic, and embedding Verilog subcircuits yields wrong expressions (Sum=B^B instead of A^B) plus spurious 'Contention Error' messages; issue open 'due to a large number of bugs' (#5328, #1753, #251) (https://github.com/CircuitVerse/CircuitVerse/issues/5328)
- Subcircuit bugs: output nodes silently disconnect when a subcircuit's layout width is changed (#349), insert-subcircuit dialog overflows with many circuits (#899), long names break the dialog (#1711), no reordering (#84) (https://github.com/CircuitVerse/CircuitVerse/issues/349)
- Cryptic error reporting — 'Contention Error: NaN and NaN at ConstVal' class messages; issue #2198 'Make error message user friendly' (https://github.com/CircuitVerse/CircuitVerse/issues/2198)
- Timing model isn't real time — per-element 'delay' is a queue priority, and clock/flag/simulation-step timing are 'completely unsynchronized' (#1412), so the timing-diagram panel can't be trusted for delay/race teaching (https://github.com/CircuitVerse/CircuitVerse/issues/1412)
- Weak project portability/organization — no folder structure for projects (#3335, top-reacted open issue), and long-running requests for proper download/upload of circuits for offline use (#2236, #477) (https://github.com/CircuitVerse/CircuitVerse/issues/3335)
- Instructor friction in groups/assignments — only the group creator can create and grade assignments (#2050), grading is manual and only after deadline, and Google Classroom is unsupported (#2661) (https://github.com/CircuitVerse/CircuitVerse/issues/2050)

## DEV COMMUNITY
GSoC is the engine and the failure mode. CircuitVerse has been a GSoC org every year since 2019 (continuing into 2026), so the contributor base is a yearly wave of students: they arrive in spring, ship a feature by September (LTI/LMS 2021, platform improvements 2022, stability + Vue simulator 2023, Flutter upgrade + Tauri desktop + Verilog stability 2025), write a final-report blog post, and mostly leave; the best alumni recycle as next year's mentors (e.g., Aman Asrani, GSoC'24 contributor → GSoC'25 mentor). The permanent core is very small — effectively a handful of maintainers reviewing everything — which shows up as a 612-open-issue backlog on the main repo, 75 open PRs on cv-frontend-vue, and years-old bugs (#349 from 2019, #1412 from 2020) that never get owned between summers. Depth vs churn verdict: the model produces breadth without depth — the flagship example is the Vue simulator rewrite, started ~2021-2023 and still running v0/v1 parallel trees behind a feature flag in 2026, and the yosys fork that silently fell 39 PRs behind upstream until a GSoC student noticed. What ATTRACTS contributors: the brand and GSoC stipend, a genuinely low-friction dev on-ramp (Codespaces one-click env with video walkthrough, active Slack, beginner-issue labels), MIT license, and resume value of a 1.2k-star edu platform. What REPELS: the ES5 jQuery canvas simulator core nobody wants to touch, the split-brain Rails/JS/Vue/Tauri/Flutter surface area, review latency outside GSoC season, and the knowledge that deep engine work (timing semantics, performance) is unglamorous versus UI features that make good GSoC deliverables — so engine correctness structurally never gets fixed.

## SWITCH ANALYSIS
### pull_users
Brutal honesty first: the mass of CircuitVerse users (intro students doing zero-install homework in a browser tab, sharing by URL) is NOT pullable to a desktop jar — the web is the whole reason they're there. The pullable slices are: (1) INSTRUCTORS WHO GRADE — CircuitVerse grading is manual, per-student, after-deadline, with grades typed against a scale; JLS's batch CLI vector grading (-t), VCD/SVG artifacts, and documented determinism contract is a categorically better grading pipeline for any class over ~30 students. (2) COURSES BURNED BY ENGINE BUGS — anyone teaching propagation delay, races, or hazards on CircuitVerse is teaching on a queue-priority pseudo-delay (#1412) with spurious contention errors; JLS's delay-accurate discrete-event sim with documented semantics is the honest tool for that unit. (3) VERILOG-ADJACENT COURSES — CircuitVerse's Verilog round-trip demonstrably produces wrong logic (#5328); JLS's structural Verilog+VHDL export is a real bridge to ModelSim/FPGA courses. (4) OFFLINE/LOCKED-DOWN environments (exam machines, air-gapped labs, districts that block accounts) where signed installers + reproducible builds are a feature, not friction. MIGRATION COST: currently prohibitive — JLS cannot read .cv project JSON, so every existing circuit and course asset is stranded; CircuitVerse's format is plain JSON, so a .cv importer is feasible and is the single highest-leverage migration lever. Evaluation cost also matters: a CircuitVerse user's first question is 'can I try it without installing', and today JLS's answer is no.
### pull_devs
Pullable: the small minority of CircuitVerse contributors who care about simulation-engine correctness and are demoralized by the 4-year Vue rewrite, the untouchable jQuery core, and the PR backlog. JLS's pitch to them is real: a coherent single-language codebase with mutation testing, NullAway, warnings-as-errors, 23 ratchet/contract files, reproducible builds, and a maintainer who reviews and decides — the exact inverse of CircuitVerse's review bottleneck. Also pullable: GSoC-alumni types who want their work to survive (CircuitVerse features rot between summers; JLS's contract tests keep shipped behavior shipped). NOT pullable: the majority — CircuitVerse's contributor pool is web-JS/Rails students chasing GSoC brand value; Java/Swing has negative resume gravity for them, and JLS (3 stars, no org, no GSoC) offers no credential. Any dev pull requires JLS to first be visibly alive: screenshots, a demo, and a few merged outside PRs.
### jls_deficits
(1) No web version — fatal for CircuitVerse's core segment; until JLS runs in a browser (CheerpJ/JWebAssembly demo, even read-only), 'zero-install classroom' users have no reason to look. (2) No chronogram/timing-diagram panel — CircuitVerse HAS one; JLS's superior timing engine is invisible without waveform UI, which is embarrassing given timing rigor is JLS's flagship claim. (3) No sharing/collaboration/gallery/LMS — CircuitVerse has URLs, embeds, groups, LTI grade passback; JLS has files. (4) No .cv importer — stranded assets block every migration. (5) Zero social proof: 3 stars, no screenshots in README, unknown brand vs 1.1M hosted circuits. (6) Swing-era look and a 5,852-line god class undercut the 'elegance' pitch on first inspection. (7) No mobile story at all (CircuitVerse has Flutter apps). (8) 2-state value domain means JLS can't claim X-propagation superiority either — its semantics edge is delay/determinism, not value-domain richness.
### winnable_verdict
WINNABLE SEGMENT: instructors and upper-division courses — specifically graders (batch vector autograding vs their manual grading is the single sharpest wedge, since CircuitVerse's own LMS integration only passes back hand-entered grades) and timing/HDL-focused courses hit by engine and Verilog correctness bugs. Also the offline/locked-down lab niche. NOT WINNABLE without a browser story: intro-class students, the 1.1M-circuit social ecosystem. MINIMUM BAR TO CLEAR: (a) CircuitVerse JSON importer so course assets migrate for free; (b) chronogram panel so JLS's timing superiority is demonstrable, not aspirational; (c) README screenshots + a browser-runnable demo (even CheerpJ-wrapped) to cut evaluation cost to CircuitVerse levels; (d) a published head-to-head correctness/grading white paper reproducing #5328/#1412-class failures in CircuitVerse and showing JLS getting them right with autograded vectors. Without (a) and (c), the pull is theoretical regardless of technical superiority.
