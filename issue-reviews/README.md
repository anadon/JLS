# Issue Reviews — 2026-08-08

Two independent reviews of every GitHub issue open on 2026-08-08 (605 issues), one file
per issue per lens:

- `issue-NNNN.adversarial.md` — adversarial review (Claude Sonnet 5): hidden assumptions,
  contradictions, underspecified or untestable acceptance criteria, feasibility and cost
  risk, ways the stated verification could pass while the real goal fails.
- `issue-NNNN.visionary.md` — visionary design/architecture review (Claude Opus 5):
  judges the issue against the greater alignment of the project rather than its stated
  imperatives, and proposes radically better or simpler routes where one is visible.

Each file opens with a header (issue number, title, lens, date, reviewer model) and a
one-word verdict. Adversarial verdicts: sound / sound-with-concerns / needs-rework /
should-not-proceed. Visionary verdicts: endorse / endorse-with-reframing / rethink /
redirect.

Generated by a Claude Code multi-agent workflow (one agent per issue per lens; 1,210
agents total). Reviews are advisory input for triage, not dispositions.
